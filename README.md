## 使い方

### 1. ファイルを手元にコピーする

`CLAUDE.md` `.gitignore` `.claude/settings.json` を、自分の作業フォルダにコピーします。
フォルダの中はこんな形になります。

```
Documents/
└── claude-workshop/
    ├── CLAUDE.md
    ├── .gitignore
    ├── .env            ← 自分で作る。GitHub には送らない
    ├── .claude/
    │   └── settings.json
    └── stock_news.py   ← 講座で Claude Code に作ってもらう
```

### 2. `.env` を作る

`.env.example` をコピーして、名前を `.env` に変えます。
`=` の右側に、自分の NewsAPI のキーを貼ってください。

```
NEWS_API_KEY=ここに自分のキーを貼る
```

**`.env.example` はキーの名前だけを書いたファイルです。**
値は絶対に書かないでください。こちらは GitHub に送っても大丈夫なものです。

### 3. 必要なライブラリを入れる

```
py -m pip install python-dotenv requests
```

`py -m pip` がうまくいかない場合は `pip` だけでも動きます。
Mac の方は `python3 -m pip` です。

## NewsAPI の無料枠について

登録は無料ですが、開発・テスト用の枠なので制限があります。

- 1日 100リクエストまで
- **記事が24時間遅れます**
- 検索できるのは過去1ヶ月分まで
- 商用利用・本番公開は不可

**リアルタイムの投資判断には使えません。**
この講座でやるのは、ニュースを集めて整理するところまでです。

## 秘密の情報の扱い

この講座でいちばん大事なところです。3つの仕組みで守ります。

1. **`.env` に置く** — コードに直接書かない
2. **`.gitignore` に入れる** — GitHub に送らない
3. **`.claude/settings.json` で読み取りを拒否** — AI にも渡さない

### 3つ目には限界があります

`settings.json` の `deny` で止まるのは、Claude Code のファイル読み取り機能です。
ターミナルから `cat .env` のように直接開く経路までは止まりません。

**1つで守ろうとせず、3つ重ねてください。**

### もし漏れたかもしれないと思ったら

APIキーを失効させて、発行し直してください。無料です。
一度 GitHub に送ってしまったものは、後から `.gitignore` に書いても履歴に残ります。

---

## うまくいかないとき

エラーは失敗ではなく、**Claude Code に渡す材料**です。

1. エラーメッセージを消さずに、そのままコピーする
2. Claude Code に貼って「原因を説明して」と頼む
3. ただし、`.env` の中身と APIキーは絶対に貼らない
4. 一度に全部直そうとせず、1つ直して、動かして、確認する
